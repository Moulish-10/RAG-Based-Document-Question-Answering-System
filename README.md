# BlueIT RAG-Based Q&A System 📄🤖

This project demonstrates a **Retrieval-Augmented Generation (RAG)** based Question & Answer system that allows users to ask questions about a company document and receive accurate, context-aware answers.

The system uses a **Terms and Conditions PDF** of a fictional company called **Blue IT Company** as the knowledge source.

---

## 🚀 Features

- PDF-based Question Answering
- Retrieval-Augmented Generation (RAG)
- Semantic search using FAISS
- HuggingFace sentence embeddings
- Google Gemini LLM integration
- Conversation memory support
- GitHub-ready clean structure

---

## 🧠 How It Works

1. Load the PDF document
2. Split text into semantic chunks
3. Convert chunks into embeddings
4. Store embeddings in FAISS vector database
5. Retrieve relevant chunks for a user query
6. Generate an answer using Gemini LLM based on retrieved context
